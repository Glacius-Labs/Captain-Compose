# Captain Compose 1.0.1

This security release updates the Go toolchain to 1.27.2 and
`golang.org/x/net` to 0.60.0. Govulncheck reported seven reachable Go standard
library findings in the v1.0.0 source; three of those findings also affected
`golang.org/x/net` 0.59.0. These updates address the reported findings. No
application behavior changes are intended.

## Install

Download the archive for your system from the GitHub release and verify its
SHA-256 checksum against `checksums.txt`. The release also includes GitHub build
attestations and offline verification bundles. Install with the included
version-pinned installer:

```bash
bash scripts/install.sh --version 1.0.1 --prefix "$HOME/.local/bin"
captain-compose-mqtt --version
```

On Windows, verify the archive with `Get-FileHash -Algorithm SHA256`, extract the
ZIP and run `captain-compose-mqtt.exe --version`.
