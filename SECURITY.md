# Security policy

Use the latest published stable release. Until a stable release is published, this
repository is under active hardening and carries no supported production release.

For private disclosure, use [GitHub private vulnerability reporting](https://github.com/Glacius-Labs/Captain-Compose/security/advisories/new)
when available. If disabled, ask a repository maintainer for a private reporting
channel without posting vulnerability details or credentials publicly.

See [the security model](docs/security.md) for deployment responsibilities and trust
boundaries. MQTT command publishers and the agent's Docker account have host-level
administrative authority.
